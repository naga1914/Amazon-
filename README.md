# 🛒 Amazon Clone

A **fully responsive and interactive e-commerce website** inspired by Amazon, developed using **HTML**, **CSS**, and **JavaScript**. This project demonstrates front-end web development skills, with an emphasis on user experience, responsive layouts, and dynamic content rendering.

## 🚀 Features

- ### 🏠 Home Page  
  A clean, modern homepage featuring:
  - A responsive navigation bar  
  - Hero product carousel  
  - Featured product sections

- ### 📱 Responsive Design  
  - Mobile-first approach  
  - Fully adaptable layout for all screen sizes using **Flexbox** and **CSS Grid**

- ### ⚡ Interactive UI  
  - Functional search bar (static/dynamic)  
  - Hover animations on product cards and navigation items  
  - Dynamically rendered product listings
